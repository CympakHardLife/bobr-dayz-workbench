# Интерфейс и меню

Определи loading/empty/error/ready. Админские права проверяет сервер. Получение
ответа RPC не должно зависеть от ближайшего NPC. Для «ждём ответа сервера» нужны
timeout, request ID, повтор и явная ошибка вместо вечного пустого окна.

Начни с api/gui.md и owning widget API. Проверь имена/типы, handlers, регистрацию
и удаление. Не использовать Reforger GUI API как DayZ API. layout-audit может
проверять только доступную статику; не называй его рендером движка.

Проверь anchors/relative units, clipping, z-order и текст на нескольких экранах.
Отдельно ввод/фокус/возврат управления игроку и повторное открытие. Длинные
списки не перестраивай полностью каждый tick. Результат — layout/скрипты,
состояния и границы фактического preview/client/server теста.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
