# Независимое ревью

Работай read-only. Вход — acceptance, diff, owning файлы и evidence. Не читай весь
корпус и не повторяй пройденные проверки без нового основания. Проверь types/access/
null, layer/side/load order, RPC authority, persistence, cleanup/cancel и budget.

Выделяй конкретный trigger/последствие/file:line и минимальную проверку. Вкусовое
оформление не blocker, если не скрывает дефект. Конфликт проверь по реально
подключаемому provider и позднему override, а не наличию папки.

Для task review сверь acceptance и актуальные evidence hashes. Не принимай свою
реализацию под другим actor. При непроведённой важной ступени допустим только
явно ограниченный статический результат. Выход — findings по важности либо
заключение с границами просмотренного; число тестов не доказывает coverage.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
