# Память и контекст

Старт: AGENTS, PROFILE, CURRENT. Затем INDEX и только нужная тема через
`python tools/memory/context_router.py --topic <тема> --read`.
Для code knowledge используй `bobr.py search --help`: внешний индекс необязателен.
Карточки содержат решение, источник, статус, границы и следующий шаг, а не весь чат.
experience.json хранит user_decision/source_confirmed/runtime_confirmed/hypothesis;
исправление явно ссылается на supersedes. Не повышай статический успех до runtime.
После значимой записи выполняй `bobr.py snapshot`, затем `bobr.py verify`.
Checkpoint — ручной allowlist снимок, без автослужб и чтения переписки.
Cache в data-root производный; его очистка не удаляет память и исходники.

Короткий диагностический урок оформляй как: симптом → различающая проверка →
действие → полученное доказательство и границы. Исправленный вывод связывай
с прежним через supersedes. Чужой журнал сбоев подсказывает гипотезу; общий запрет
движка требует owning source или воспроизводимого подтверждения.

# Контракты разработки DayZ

Перед кодом зафиксируй класс, owning файл и полную сигнатуру, слой 1_Core/2_GameLib/
3_Game/4_World/5_Mission, сторону исполнения, видимость и цепочку modded/override.
CfgMods.files задаёт включённые scripts, requiredAddons ссылается на CfgPatches
providers. Папка Workshop сама не доказывает загрузку. Client UI/RPC требует клиента.

При переносе вызова проверь def-use всех имён, тип каждого аргумента, callers,
guards и lifecycle. Изменение одного метода может требовать обновления зависимых
вызовов. Не подставляй похожее имя, нулевую collision mask или принудительный true.
Не раскрывай protected случайным wrapper: используй подтверждённый публичный API.

Предпочитай Allman и 4 пробела, короткие законченные выражения и вызовы на одной
физической строке. Это консервативная дисциплина, не полная спецификация Enforce.
Проверяй class/local name collisions, совместимость Cast по наследованию,
повторные locals и числовой контекст. Integer remainder нельзя массово заменять
float-операцией: большие int теряют точность. Каждый fallback требует контракта.

У AI один владелец движения. Событие обновляет память/приоритет, отменяет устаревшее
поколение пути, затем планирует ограниченную работу. lastSeen и lastHeard разделены;
невидимую цель нельзя отслеживать по её живой позиции. Сохраняй Y/этаж наблюдения.
Navmesh маршрут дополняй clearance тела, hysteresis, stuck timeout и bounded recovery.
Ray/path work ограничивай бюджетом на кадр и общей очередью. Сценарии включают отмену,
смерть/cleanup, двери, лестницы, узкие проходы, повторный шум и несколько игроков.

Слои stimulus → memory → decision → route → movement/action проверяй отдельно.
Внешняя механика служит источником принципов; runtime-совместимость и лицензия
требуют самостоятельной проверки. CPU/нагрузку доказывай измерением в игре.
