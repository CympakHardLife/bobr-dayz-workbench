# Наблюдаемые сценарии

Сохрани build hashes, карту/миссию, load order, исходное состояние, действие,
наблюдаемый успех, timeout и отказ. План сценария не является запуском.

- Голос: несколько фраз после cooldown; источник/дистанция, отмена при удалении.
- Поиск: lastSeen затем свежий lastHeard в другой стороне; старая команда не
  возвращает NPC бесконечно и новый шум не забывается из-за старой цели.
- Здание: шум за стеной, обычная/запертая дверь, цель выше головы; отдельно
  проникновение, линия видимости и заданная suppression политика.
- Движение: узкий проход/лестница/встречные NPC, physical clearance, отмена пути;
  ограниченное время stuck без бесконечного «вальса».
- Лечение: threat priority, корректные complete/cancel без animation lock.
- Кусты/окна: visibility и penetration отдельно, игрок виден разными hitpoints,
  стекло целое/разбитое; не только head-only проверка.
- UI: ответ без близкого NPC, права/timeout/retry, ввод/фокус, reconnect, экраны.
- Предметы: spawn/hands/equip/attach/cargo/drop/ruin; это не Human AI тест.

Нагрузка: NPC count, частота perception/path, распределение по tick и выбранные
server frame показатели. Сравнивать одинаковую сцену с несколькими повторами.
