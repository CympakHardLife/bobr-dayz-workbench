# Коллизии и пространственные проверки

Раздели физическую collision, view/fire geometry, navmesh и scripted raycast.
Слой/маску/output types подтверждай по точной сигнатуре owning API. Маску из
Reforger или комментария не переноси автоматически.

Для прохода учитывай физический объём/позу тела, не одну линию skeleton centre.
Воспроизведи stuck на одном объекте, фиксируя позиции/command owner. Установи
лимит частоты/числа rays и path updates; кешируй устойчивое, инвалидируй при
движении. NPC распределяй по времени, не полная сетка каждый кадр.

Результат — owning схема, локальная правка, бюджет и сценарии угол/узкий проход/
лестница/движущийся объект. Для Human AI используй dayz-ai-engineering.
Улучшение нагрузки подтверждай одинаковой сценой и измерением server frame/p95,
а не числом строк исходника.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
