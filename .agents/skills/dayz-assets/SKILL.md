# Модели, материалы и текстуры

Начни с resource-audit и texture help. Аудит заголовков/путей не подтверждает
геометрию P3D или правильность материала. Различай source MLOD и binary ODOL;
закрытую модель не декомпилируй ради обхода ограничений.

Для текстуры проверь размеры, alpha, назначение и карту материала. ImageToPAA
конвертирует, но не оценивает художественную/шейдерную правильность. Сохрани
исходник, output в настроенном data-root, проверь новый PAA. Не переименовывай normal в color ради lint.

При ошибке конвертации проверь декодируемость входа, каналы, bit depth и alpha
доступным инструментом. Нормализуй копию только при выявленной несовместимости,
сохраняя назначение карты и alpha; один сбой не запрещает формат или экспортёр.
Новая библиотека для этого не устанавливается автоматически.

Для доступной модели проверь resolution/geometry/fire/view LOD, named selections,
memory points, proxies, mass и model.cfg. Collision/action/visibility — разные
контракты. Результат — ресурсы, карта ссылок, конкретные дефекты и отдельный
план осмотра в Object Builder/игре. Нечитаемый binary помечай непроверенным.

После импорта/экспорта модели сверь единицы, оси, ориентацию и bounding box с
ожидаемыми габаритами предмета; повторная смена единиц может масштабировать его
дважды. Не используй коэффициент из чужого проекта без измерения. До переделки
правильного ресурса проверь его virtual path/prefix, entry текущего PBO и SHA
установленной сборки: старый payload и дефект материала требуют разных действий.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
