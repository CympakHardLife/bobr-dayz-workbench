# Звук и озвучка

Проследи source → conversion → PBO entry → SoundShader → SoundSet → script.
Сохраняй проверенный consumer contract проекта: расширение, codec/channels, имена
и виртуальные пути. Для DayZ проверяй OGG на целевой цепочке; переименование не
конвертация. 3D источник привязывай к говорящему объекту/позиции, проверь range,
attenuation, cleanup и cooldown. Громкость не исправляет источник у головы слушателя.
Проверки: близко/средне/далеко, поворот, здание, дождь, новый пак, повторная реплика.
Pitch меняет высоту/восприятие, отдельную смену тембра не обещай. Radio-filter —
отдельная задача. Static цепочка не подтверждает слышимость в игре.
