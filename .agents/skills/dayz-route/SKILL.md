# Выбор навыка и специалиста

Используй `route --query "задача"`, прочитай role/skills и причины выбора.
Ключевые слова помогают выбрать исполнителя, но не доказывают понимание задачи.
При нескольких доменах ведущий определяется owning контрактом изменения.

Точная ошибка загрузки сначала идёт debugger; новый многосоставной мод —
architect/orchestrator. Не отправляй весь корпус всем специалистам. Два домена
могут потребовать исполнителя и независимую проверку, а не две правки одного файла.

`team list` показывает сохранённые роли. Профиль — инструкция, не запущенный
процесс. Реального помощника вызывай доступным инструментом хоста с bounded
brief. Результат — ведущий, skills, owning файлы, пробелы данных и следующий
исполнимый шаг. Неясность сначала исследуй по доступному проекту.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
