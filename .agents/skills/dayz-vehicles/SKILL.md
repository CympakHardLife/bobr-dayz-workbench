# Транспорт

Начни с api/vehicles.md и конкретного vanilla parent. Сверь crew seats/memory
points, actions, doors, attachments и model.cfg. Отдели config drivetrain,
server authority и клиентскую анимацию. Не меняй весь drivetrain ради одного seat.

Для NPC: резервирование места, подход к двери, отказ и освобождение при смерти
или удалении. Телепортация в seat не доказывает правильную посадку/выход.
Физические параметры сравнивай с близким vanilla примером по единицам.

Результат — script/config/model dependency map и сценарии движения, damaged wheels,
посадки, выхода, reconnect/persistence. Устойчивость физики требует игры и
измерения; линтер её не подтверждает. Сетевую задержку проверяй отдельно.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
