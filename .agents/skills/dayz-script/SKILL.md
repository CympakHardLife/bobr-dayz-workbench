# Enforce, RPC и сохранение

Найди owning объявление и caller. Подтверди сигнатуру, access, родителя, слой,
сторону, guards и поздний modded override. Необходимость super следует из
контракта. Указатели базы: api/network_rpc.md, actions.md, inventory.md.

Раздели authority сервера и клиентское представление. RPC проверяет отправителя,
права, входные диапазоны и актуальность объекта на сервере. Меню не выдаёт прав.
Укажи timeout/retry/idempotency: повтор запроса не создаёт вторую награду/регистрацию.
Для callbacks/CallLater проверь владельца, отмену и удаление при смене миссии.

Сохранение — по [контракту persistence](references/persistence.md). Runtime Object
не устойчивый ID. Выполни адресные применимые Enforce checks. Незавершённые
выражения нового кода держи на одной физической строке по code_style.md.
Результат — код и сценарии успеха/повтора/отмены/рестарта, Enforce/runtime отдельно.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
