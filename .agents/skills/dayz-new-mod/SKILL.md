# Создание собственного мода

Определи назначение, клиентские ресурсы/меню и серверную authority. Выбери имя,
namespace и стабильный PBO prefix. Имя папки не заменяет виртуальный путь.
Для новой папки используй scaffold; существующий мод сначала исследуй и дополни
минимальным diff, не перезаписывай каркасом.

Проверь CfgPatches providers/requiredAddons, CfgMods.files, слои Game/World/Mission
и пути ресурсов. Новое клиентское soundset/UI нельзя обещать как server-only.
Для пары client/server запиши две отдельные build-цели и порядок загрузки.
P:-junction не обязателен для создания исходников.

Результат — исходники, карта зависимостей и наблюдаемый минимальный сценарий:
что появится, на какой стороне, когда удалится и как проверить повторную
регистрацию. Scaffold не подтверждает правильность нового gameplay API.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
