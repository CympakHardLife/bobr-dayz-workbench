# Карта и размещение

Установи карту и owning mission. Namalsk/Chernarus — независимые контексты:
сходное имя локации не переносит координаты/высоту/config. Сверь координатную
систему, orientation, terrain height и способ сохранения объектов.

В лагере отдели static composition от spawn/patrol logic. Проверь входы, ширину,
лестницы и возврат. Объект в редакторе не доказывает navmesh в игре. До массового
размещения проверь небольшой участок и бюджет сетевых сущностей.

Укажи server creation/cleanup/respawn/restart. Не дублируй persistence объектом,
создаваемым каждым init. Результат — отдельные данные, loader, тестовая зона
и проверенные координаты. Живую миссию менять по поручению с адресным diff.

Команды вызываются из корня репозитория через `.\bobr.ps1`; точный синтаксис —
`commands` и `<команда> --help`. Общие правила — AGENTS.md.
